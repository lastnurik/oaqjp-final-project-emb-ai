# Final Project

Emotion detection web application built with Flask and the Watson NLP service.

Run `python3 -m pip install -r requirements.txt`, then `python3 server.py`. Open port 5000 to enter text and view emotion scores.

Run `python3 test_emotion_detection.py` to test the five required emotions against the live Watson service. The service is provided by IBM Skills Network and must be reachable from the runtime.
